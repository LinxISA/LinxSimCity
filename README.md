# LinxSimCity

LinxSimCity is a WebGL trace visualizer for Linx processor and matrix-compute models. It provides a versioned trace contract, tooling, a dependency-light C++ writer SDK, and an interactive browser viewer.

## Development

Use Node.js 22 or newer, then install dependencies and run the repository checks:

```sh
npm install
npm run check
```

The npm workspace includes packages under `apps/*`, `packages/*`, and `tools/*`.
